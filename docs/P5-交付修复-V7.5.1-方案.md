# P5 · 交付修复方案（V7.5.1）

- 日期：2026-09-15
- 触发：AprilPark1012在 Windows 上按验收清单跑 V7.5，第 3 条（慢目标闸门）**5 failed / 1 passed**
- 结论先行：**V7.5 交付包里夹带的 `scripts/test_cases.py` 是坏产物（100 处「元素未映射」存根）**，
  闸门失败是真红；根因是 `generate` 在探测不可用时**只打一句警告就继续落盘、且 exit 0**。

## 2. 修法（G1~G5，按「② AI 语义准 ≈ ① 降人力 > ③ 稳定 > ④ 脚本健壮」排）

### G1 `generate` 映射质量闸（P0 · 服务③稳定 + 防假绿）
- **判据**：生成前算 `still_missing = needed - set(loc_map)`；非空 ⇒ 打印「缺哪些 + 真因（现场 probe 失败原因 / 目标没起）+ 下一步」→ `SystemExit(2)`，**产物不落盘**（先校验后写）。
- **逃生口**：新增 `--allow-unmapped`（显式声明才允许产出带 `pytest.fail` 存根的脚本，供手写用例调试），
  ⚠️ 同时要进 `FLAG_SPECS` / `CMD_FLAGS`（CLI 参数契约）并更新 `tests/test_cli_flags.py`。
- **保留**运行时 `pytest.fail(元素未映射)` 存根（防手改脚本），但它不再是「探测失败的默认出口」。
- **新测试** `tests/test_generate_quality_gate.py`（秒级、不启浏览器、用假 `playwright.sync_api`）：
  ① 探测失败 ⇒ `SystemExit(2)` 且 `scripts/test_cases.py` **未落盘**；
  ② 带 `--allow-unmapped` ⇒ 落盘且未映射数 >0；
  ③ 正常目标 ⇒ 未映射 = 0。

### G2 目标可达性预检（P1 · 服务①降人力）
- `framework/target_probe.py` 新增 `reachability(base, timeout) -> (ok, 人话)`，**刻意区分三类**：
  连不上（ConnectionRefused）⇒ 「目标没起，先 `python -m demo.app`」/ 超时 / 可达；
  与现有 `probe_partitioned` 的「有响应但没声明分区」不再混为一谈（现在是笼统一句「未声明」）。
- `cmd_probe()` / `cmd_generate()` 前置预检：不可达 ⇒ 人话 + `SystemExit(2)`，**绝不进 Playwright**（不再吐 traceback）。
- `cmd_run()` 的并发隔离文案按上述三类改写（不改行为，只改归因）。
- **新测试**：`tests/test_target_reachability.py`（真起/真停一个 stdlib 小服务，不启浏览器）。

### G3 两个 verify 脚本补 `force_stdio()`（P2 · 服务①）
- `tests/verify_slow_target.py`、`tests/verify_picker_layer.py` 开头调用 `force_stdio()`（消除 cp936 乱码、✓/⚠️ 不再崩）。
- 源码级断言：`tests/test_utf8_io.py` 增加「`tests/verify_*.py` 必须调 force_stdio」一条（防复发）。

### G4 交付前自检（P0 · 防同类事故再进包）
- **新增** `tests/test_artifacts_health.py`（秒级、不需 demo）：
  `scripts/test_cases.py` 未映射 = 0、`_goto(` 存在、`conftest.py` 含断言辅助与 `_reset_target_data` fixture。
- **新增** `tools/pack_release.py`（替代手工 zip）：打包后用 **`zipfile`** 复扫包内生成物
  （未映射=0 + 打印 sha256），任何一项不合格 ⇒ 非 0 退出、不产出包。
  ⚠️ 铁律：**校验禁止依赖外部解压命令**（E9 就是 `unzip` 缺失造成的假绿）。

### G5 GBK guard 跨平台（已完成，待随版交付）
- `_has_gbk_locale()` → `_gbk_default_encoding()`（NT 读 ANSI 代码页 / POSIX 才用 `locale -a`）+ 家族断言 + 6 条「测试的测试」。
- 本机实测：`pytest tests/ -q` **106 passed**；`PATH=/nonexistent` 下 **103 passed + 3 skipped**（POSIX 真无 GBK，skip 正当）。
